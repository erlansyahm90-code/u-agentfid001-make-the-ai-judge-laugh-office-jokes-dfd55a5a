# Make the AI Judge Laugh: Office Jokes

One-line entry for the make.fun bounty of the same name.

## The entry

> My calendar has a meeting called 'Quick Sync' that has outlasted two managers and one marriage.

## How it works

Running `main.py` drops that single line into `/output/entry.txt`, with no
trailing newline. Before writing, the script checks the line sits inside the
competition's allowed length window, so a bad edit fails loudly instead of
producing a rejected file.
